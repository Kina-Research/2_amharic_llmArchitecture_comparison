# Data Sources and Provenance

This directory contains scripts and metadata for both datasets used in the study.
Actual data files are placed in `processed/` (gitignored) and are regenerated by
running `python scripts/prepare_data.py`.

---

## 1. Amharic Sentiment Classification (NLU)

| Field | Value |
|---|---|
| **Name** | AfriSenti — Amharic subset |
| **Hugging Face ID** | `shmuhammad/AfriSenti-twitter-sentiment` (config `amh`) |
| **Fallback HF ID** | `masakhane/afrisenti` (config `amh`) |
| **Domain** | Social media (Twitter/X) |
| **Language** | Amharic (Ge'ez script, am) |
| **Labels** | 3-class: positive, neutral, negative |
| **Official splits** | train ≈ 5,984 · validation ≈ 1,497 · test ≈ 1,999 |
| **License** | MIT |
| **Citation** | Muhammad et al. (2023). *AfriSenti: A Twitter Sentiment Analysis Benchmark for African Languages.* EMNLP 2023. |

### Processing applied

1. **Pool** official train + validation + test splits into a single frame.
2. **Clean** each text: NFC normalisation, URL removal, @mention removal, whitespace standardisation.
3. **Filter** texts shorter than 5 characters or with < 30 % Ethiopic characters.
4. **Drop conflicting duplicates** (same normalised text mapped to different labels).
5. **Deduplicate** on a normalised key (lowercased, no punctuation/digits/spaces).
6. **Split** 80 / 20 stratified on label (seed = 42).
7. **Verify** zero overlap between train and validation on the normalised key.

Statistics after cleaning are written to `processed/manifest.json`.

## 2. Amharic Abstractive Summarization (NLG)

| Field | Value |
|---|---|
| **Name** | XL-Sum — Amharic subset |
| **Hugging Face ID** | `csebuetnlp/xlsum` (config `amharic`) |
| **Domain** | BBC Amharic news articles |
| **Language** | Amharic (Ge'ez script, am) |
| **Official splits** | train ≈ 5,761 · validation ≈ 719 · test ≈ 719 |
| **License** | CC BY-NC-SA 4.0 |
| **Citation** | Hasan et al. (2021). *XL-Sum: Large-Scale Multilingual Abstractive Summarization for 44 Languages.* ACL-Findings 2021. |

### "amharic-eval-500" construction

1. **Clean** the official test split (NFC, URL removal, whitespace).
2. **Filter** articles < 200 characters or summaries < 20 characters.
3. **Deduplicate** on the article text.
4. **Sample** 500 pairs (seed = 42) — this is the **amharic-eval-500** evaluation set.
5. **Training set**: pool official train + validation, clean, remove any pair whose
   article or summary appears (by normalised key) in amharic-eval-500.

The 500 evaluation IDs and their SHA-256 checksums are recorded in `processed/manifest.json`.

## How to regenerate

```bash
# From the repository root
python scripts/prepare_data.py          # writes data/processed/*.csv + manifest.json
```

The script is deterministic (fixed seed, pinned HF dataset revision). If the
HF dataset has been updated, the `hf_revision_sha` field in `manifest.json`
will differ; re-pin it in `configs/experiment_config.yaml` if strict bit-for-bit
reproducibility is needed.
